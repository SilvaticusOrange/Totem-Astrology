### Before filing trademark

- [ ] Search [USPTO TESS](https://tmsearch.uspto.gov/) for "Totem Astrology" and close variants
- [ ] Google + social handles for conflicting uses in astrology / wellness / coaching
- [ ] Confirm consistent spelling everywhere (site, email signature, invoices, social bios)
- [ ] List **first use in commerce** date(s): site public, first paid reading, etc.
- [ ] Pick **Nice classes** with attorney (common: Class 41 education/entertainment, Class 45 personal services, Class 42 SaaS if calculator/directory is commercial)
- [ ] Save screenshots / archives of site showing mark in use
