Registration Roadmap

If you are Travis (or advising him) and preparing formal filings, these are the primary assets worth discussing with an IP attorney or the USPTO:

Trademark candidates

  • Totem Astrology — primary service and system name (word mark)
  • TotemAstrology.com — domain / brand identifier (word mark)
  • Earthly Wisdom for your Journey — homepage tagline (consider as slogan mark if used consistently in commerce)
  • Site logo — compass / cross-circle mark in the header (design mark, if filed separately)

Copyright candidates

  • Website compilation — totemastrology.com as a collective work
  • Animal guide library — main modal copy in the calculator (totem-details.js)
  • Element lore — sixty element-animal closing paragraphs (totem-element-lore.js)
  • Educational pages — How It Works, Values Triangles, Yin & Yang, etc.
  • Original artwork — totem animal images, zodiac wheel, five-elements diagram
  • Software — calculator and connections source code (optional registration if commercial value grows)

Before filing — quick checklist

  1. Run a clearance search (USPTO TESS, web search, social handles) for conflicting marks
  2. Confirm consistent spelling: Totem Astrology and TotemAstrology.com
  3. Choose Nice classes with your attorney (e.g. consulting/readings, educational content, online software)
  4. Document first use in commerce — site launch, readings sold, public promotion dates
  5. Keep copies of key versions of copy and art as evidence of authorship
  6. After registration, update ™ to ® only on marks that were actually registered
